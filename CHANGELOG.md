## [Unreleased] — рефакторинг, фазы 0–3

### Архитектура (фаза 2)
- **`ToolBase`** — базовый класс инструмента: lifecycle `start/suspend/resume/cancel/apply/destroy`, единое владение `pe.activeTool`, overlay-canvas с учётом `devicePixelRatio` (чёткие рамки и ручки на HiDPI), `ResizeObserver` на изображении с `onViewResize(kx, ky)`, Pointer Events с захватом указателя и коалесингом `pointermove` в один вызов на кадр, клавиатура только через `onKeyDown`, стандартная шапка панели. Все шесть инструментов переведены на него: Adjust 547 → 390, Mask 759 → 458, Heal 992 → 407, Draw 1196 → 755, Crop 1077 → 531, Overlay 1341 → 863 строк.
- **`CardList`** — общий список карточек (наброски, области) с делегированием, `role=listbox/option`, клавиатурой.
- **`canvasUtils`** (`canvasToBlob`, `blobToImage`, `imageToCanvas`, `waitForImage`, `clientToLogical`, `afterRender`), **`utils`** (`isEditableTarget`, `escapeHtml`, `safeCssColor`).
- **`healAlgorithm.js`** — алгоритм ретуши вынесен в чистые функции (без DOM, готов к Web Worker), unit-тесты.

### Производительность (фаза 3, начало)
- **`PhotoEditor.commitCanvas(canvas)`** — результат инструмента фиксируется как PNG Blob → `blob:` URL; `toBlob` кодирует вне главного потока, base64 в `img.src` больше нет, редактор отзывает устаревшие URL.
- **История без потерь**: `HistoryManager` хранит тот же PNG Blob (без перекодирования) и возвращает Blob; раньше снапшоты пережимались в lossy WebP и каждый undo подменял изображение.
- **HealTool**: рабочие массивы алгоритма — в окне bbox компоненты, а не на весь кадр (для 12 Мп было ~200 МБ на компоненту); источник пикселя у края/в маске берётся от ближайшего граничного пикселя; край изображения не считается границей маски.
- **MaskTool**: пикселизация области кэшируется и пересчитывается только при изменении геометрии/блока (раньше `getImageData` на каждую область на каждый `mousemove`).
- **OverlayTool**: `pointermove` без операции не перерисовывает canvas и панель.
- **AdjustTool**: рабочие буферы превью переиспользуются, полноразмерный `ImageData` освобождается при `suspend`.
- **DrawTool**: миниатюры пересчитываются по `change` цвета, а не на каждое движение в пикере.

### Поведение
- Рамка кадрирования не выходит за изображение (прозрачных полей в результате больше нет); после поворота на 90° ставится заново под новый размер.
- Толщина линии DrawTool масштабируется вместе с окном; прямую линию с нулевым bbox можно выбрать.
- Данные из `localStorage` (цвета, числа, URL, история оверлеев) валидируются при чтении.
- Тип оверлея сериализуется явным полем `type` (раньше `constructor.name`, ломалось минификацией).

### Исправления (фаза 1)
- **Escape в DrawTool/MaskTool закрывал редактор целиком** вместо отмены инструмента. MaskTool слушает клавиатуру в capture-фазе, как Draw/Heal.
- **Backspace/Delete/стрелки/Escape внутри текстового поля оверлея** удаляли, двигали и сбрасывали оверлеи. Горячие клавиши редактора и инструментов игнорируют события из редактируемых элементов (`utils.isEditableTarget`); Escape в поле снимает фокус.
- **Открытие панели Импорт/Экспорт сбрасывало рамку кадрирования**; теперь CropTool приостанавливается (как OverlayTool) и восстанавливает рамку при возврате.
- **После undo → redo редактор закрывался без диалога подтверждения** — флаг изменений возвращается при redo.
- **Панель истории оверлеев накапливала обработчики клика** при каждой перерисовке: один клик удалял несколько записей / запускал восстановление N раз.
- **Heal/Mask/Adjust экспортировали результат в источник при каждом «Применить»** (в режиме `<input type=file>` файл подменялся до записи в историю), вопреки поведению 3.6 и остальных инструментов. Также убраны вызовы удалённого `pe._handleToolStop`.
- **AdjustTool: серые пиксели краснели** при Saturation/Vibrance > 0.
- **CropTool: повторный клик «повернуть» до декодирования** давал 90° вместо 180°; слушатель `load` после поворота не снимался при уничтожении инструмента.
- **DrawTool: любой мазок дольше 2 с принудительно распознавался как фигура** — теперь только удержание неподвижного курсора.
- **Hit-test ручек** (прозрачность/углы в Draw, вращение в Overlay) только у выбранного объекта — невидимые зоны у остальных перехватывали клики.
- **HistoryManager**: параллельные `push()` не теряются (очередь вместо мьютекса); `destroy()` действительно очищает записи сессии в IndexedDB (раньше — никогда, база росла бесконечно); при старте удаляются записи брошенных сессий старше 24 ч.
- **ExportPanel**: одна кнопка «Буфер» вместо «JPG»/«PNG» — Clipboard API принимает только PNG, обе копировали одно и то же.
- **FileInput**: `bind()` идемпотентен; качество JPEG — из общей настройки, а не захардкоженного 0.85.
- XSS: имя файла/MIME в диалоге «О редакторе» и текст/цвет/URL из localStorage в истории оверлеев экранируются.
- Публичные `HistoryManager.snapshot()` и `DialogManager.hasOpen()` вместо доступа к приватным полям.
